# 🌳 Life Tree — ردیاب پیشرفت زندگی

یه اپ تک‌فایل HTML برای مدیریت اهداف، ردیابی پیشرفت، و سازماندهی زندگی با ساختار درختی نامحدود.

🔗 **دمو آنلاین:** [GitHub Pages](https://mohsen-niksirat.github.io/life-tracker/)

📱 **نصب PWA:** لینک رو توی مرورگر موبایل باز کن → Add to Home Screen

📦 **نسخه Android:** فایل `lifetree-debug.apk` رو دانلود و نصب کنید

---

## ✨ ویژگی‌ها (نسخه ۲.۲)

### 📊 داشبورد پیشرفته
- خلاصه وضعیت: درصد پیشرفت، Streak، اهداف فعال، XP
- نمودار میله‌ای هر هدف با درصد
- تقویم فعالیت ۲۸ روز اخیر
- آمار برچسب‌ها با نمودار
- دسترسی سریع به بخش‌های مختلف

### 🌳 ساختار درختی نامحدود
- اهداف با عمق نامحدود (هدف ← زیربخش ← زیرزیربخش ← ...)
- زیرتسک نامحدود — هر تسک میتونه زیرتسک داشته باشه
- ساخت گروهی هوشمند با الگو (مثلاً فصل n + n=7 → ۷ زیربخش خودکار)
- آیکون و رنگ اختصاصی برای هر هدف، زیربخش و تسک
- جابجایی با دکمه ▲▼ و Drag & Drop واقعی (موس + لمسی)
- حالت انتخاب گروهی تسک‌ها (☑️)
- 📁 بستن/باز کردن همه زیربخش‌ها

### 📋 مودال هدف ۵ مرحله‌ای
- مرحله ۱: نام + آیکون (۱۵۰+ آیکون) + رنگ
- مرحله ۲: فاصله زمانی (هر روز / یکروز در میان / هفتگی)
- مرحله ۳: تعداد زیربخش + تعداد تسک هر زیربخش
- مرحله ۴: ویرایش نهایی — اضافه/حذف زیربخش و تسک، ویرایش اسم و آیکون
- مرحله ۵: آیکون پایان + یادآوری + ذخیره

### ✅ مدیریت تسک
- تیک زدن با یک کلیک
- اولویت: 🔴 زیاد / 🟡 متوسط / 🟢 کم
- تاریخ سررسید شمسی با تاریخپیکر سفارشی
- 🏷️ تگ/برچسب با سیستم پیشرفته: آمار، رنگ اختصاصی، مدیریت
- یادداشت برای هر تسک
- 📌 پین تسک‌های مهم
- ⏱️ تایمر تسک (زمانسنج)
- فیلتر: همه / انجام نشده / مهم / سررسید گذشته / پین شده
- 🔍 جستجوی پیشرفته با فیلتر ترکیبی (اولویت + وضعیت + برچسب + تاریخ)
- Undo حذف

### ⏰ یادآوری و نوتیفیکیشن
- یادآور تاریخدار
- تکرار روزانه / هفتگی
- نوتیفیکیشن مرورگر
- 🔔 یادآوری هوشمند (تسک‌های ۳+ روز بدون توجه)

### 🍅 پومودورو
- تایمر سفارشی
- نوتیفیکیشن پایان جلسه
- شمارنده جلسات

### 📅 تقویم شمسی
- نمایش ماهانه با تاریخ جلالی
- آیکون اهداف کنار هر روز
- نمایش تسک‌های سررسید با رنگ‌بندی
- **نمایش جزئیات کامل هنگام کلیک روی هر روز:**
  - گروه‌بندی بر اساس هدف
  - اولویت، یادداشت، برچسب، زمان صرف‌شده
  - آمار ۴ خانه‌ای (کل، انجام‌شده، باقیمانده، عقب‌افتاده)
- تاریخچه ۳۰ روز اخیر

### 🌳 نمایش درختی (۹ مدل)
- 🌳 کلاسیک — درخت واقعی با تنه، شاخه، برگ و میوه
- 🔵 دایرهای — اهداف دور یه مرکز
- 🧠 ذهنی — شاخهبندی چپ و راست
- 📊 بلوکی — مستطیلهای تو در تو
- 🌌 کهکشانی — اهداف به صورت سیاره‌ها
- 🧬 عصبی — شبکه عصبی با نورون‌ها
- 📋 کانبان — نمایش ستونی تسک‌ها
- 🌸 بونسای — درخت مینیمال ژاپنی
- 🏝️ جزیره — درخت نخل روی جزیره

### 📊 آمار و گزارش
- نمودار دایره‌ای پیشرفت کلی
- نمودار میله‌ای هر هدف
- نمودار ۷ روز اخیر
- 🔥 Streak (روزهای متوالی فعالیت)
- 📈 نمودار روند ماهانه (۳۰ روز)
- 🕐 بهره‌وری ساعتی
- 📅 بهترین روز هفته

### 🎯 سیستم‌های امتیازدهی
- ⭐ XP و لول‌آپ (هر تسک = امتیاز بر اساس اولویت)
- 🏆 ۱۰ نشان و دستاورد
- 🎬 امتیازدهی سریال (سر وقت +۱۰، دیر +۵، بونوس سری)

### 🎯 چرخه زندگی
- نمودار عنکبوتی ۸ بُعدی (سلامت، مالی، روابط، کار، تحصیل، تفریح، معنویت، فیزیکی)
- امتیازدهی ۱-۱۰ با اسلایدر
- پیشنهادات بر اساس کمترین امتیاز

### 😊 ردیاب خلق
- ۵ حالت: 😊 خیلی خوب، 🙂 خوب، 😐 معمولی، 😢 بد، 😡 خیلی بد
- تقویم ۲۸ روزه با ایموجی
- نمودار روند خلق

### 💰 ردیاب مالی
- ثبت درآمد/هزینه با ۱۰ دستهبندی
- نمودار ماهانه
- خروجی CSV

### 💧 ردیاب آب
- ۸ لیوان روزانه
- انیمیشن پر شدن
- استریک + یادآوری

### 😴 ردیاب خواب
- ساعت خواب/بیداری
- کیفیت خواب
- نمودار ۷ روزه

### 📋 خلاصه روزانه
- گزارش خودکار: تسک‌ها، XP، خلق، آب، مالی

### 🎯 حالت فوکوس
- تمام‌صفحه فقط تسک فعلی
- تایمر بزرگ

### 📤 اشتراک‌گذاری
- کارت پیشرفت زیبا
- خروجی PDF، CSV و JSON
- 💾 بکاپ/بازیابی JSON کامل

### 🎨 سفارشی‌سازی
- **۱۰ تم:** تاریک، روشن، جنگلی، اقیانوسی، کویری، شبانه، غروب، اسطوخودوس، ساکورا، نئون
- 📋 حالت مینیمال (فقط تسک‌ها)
- ۱۰ قالب آماده (زبان، سلامت، پروژه، کتاب، سریال، ...)
- بکاپ خودکار روزانه
- 🎛️ سفارشی‌سازی نوار پایین (انتخاب ۵ دکمه از ۱۴ گزینه)

## 📱 نصب

### وب (PWA)
1. فایل `index.html` رو دانلود کنید
2. توی مرورگر باز کنید
3. برای نصب PWA: مرورگر موبایل → Add to Home Screen

### Android
1. فایل `lifetree-debug.apk` رو دانلود کنید
2. روی گوشی نصب کنید (ممکنه نیاز به فعال‌سازی "نصب از منابع ناشناخته" باشه)

---

## 📦 ساخت نسخه Android

```bash
# پیش‌نیاز: Node.js 18+, JDK 21, Android SDK 34

# نصب Capacitor
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android

# کپی فایل‌های وب
mkdir -p www
cp index.html service-worker.js manifest.json www/
cp -r icons www/

# اضافه کردن Android
npx cap add android
npx cap copy android

# بیلد Debug
cd android && ./gradlew assembleDebug

# بیلد Release (برای Google Play)
./gradlew bundleRelease
```
